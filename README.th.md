# goal-meter

## ความสามารถ

**ความคืบหน้า**

- **เป้าหมาย งานหลัก งานย่อย** งานที่กำลังทำแตกงานย่อยเป็นต้นไม้
- **สีประจำงาน** ใช้ทั้งในแถวงานและในช่วงของแถบความคืบหน้ารวม งานที่เสร็จเติมสี งานที่กำลังทำกระพริบ งานที่ยังไม่เริ่มเป็นสีเทา
- **ดูสถานะได้ทันที** `✔` เสร็จ (เขียว) · `◐` กำลังทำ (เหลือง หมุน) · `○` ยังไม่ทำ (เทา)
- **อัปเดตเอง** Claude เรียก tool `update` เอง และถ้า Claude ใช้ task list ของ Claude Code (`TodoWrite`, `TaskCreate`, `TaskUpdate`) meter ก็ตามรายการนั้นให้อัตโนมัติ

**เวลา**

- **นับเวลาทำงานจริง** นับเฉพาะตอน Claude กำลังทำงาน พักไปกินข้าวก็ไม่ทำให้ ETA เพี้ยน แสดงทั้งสองแบบ: `ทำงานจริง 12m (ผ่านไป 40m)`
- **ETA ที่เรียนรู้** ทุกเป้าหมายที่เสร็จจะบันทึกว่าคาดการณ์ตอนครึ่งทางคลาดไปเท่าไร แล้วปรับ ETA ครั้งต่อไปด้วยค่ากลางของประวัติ
- **Deadline** `/goal-meter deadline 17:00` บอกว่าทันกำหนดไหม หรือจะช้าไปเท่าไร
- **หยุดนับ** `/goal-meter pause` / `resume` หรือกดปุ่มใน pane

**ค่าใช้จ่ายและโควต้า**

- **ค่าใช้จ่ายต่อเป้าหมายและต่องาน** คิดจากค่าใช้จ่ายของ session ระหว่างเริ่มถึงเสร็จ
- **โควต้า** 5 ชั่วโมงและรายสัปดาห์ในบรรทัดเดียว พร้อม % และเวลารีเซ็ต
- **คาดการณ์โควต้าหมด** จากอัตราที่ใช้ในรอบนี้ เช่น `5 ชม. หมดราว 15:40` และขึ้นเตือนสีแดงถ้าโควต้าจะหมดก่อนงานเสร็จ
- **เตือนโควต้า** ที่ 80% และ 90% เป็น toast และเสียง รอบละครั้ง

**อื่น ๆ**

- **Subagent** agent ที่ Claude แตกออกไปแสดงใน pane ระหว่างทำงาน และนับจำนวนในแถบเหนือช่องพิมพ์
- **รายงานและประวัติ** `/goal-meter report` สรุปเป็น Markdown สำหรับ standup, `/goal-meter history` ดูเป้าหมายที่เสร็จแล้วพร้อมเวลาและค่าใช้จ่าย
- **ต่อข้าม session** เป้าหมายที่ยังไม่เสร็จจะอยู่ต่อใน session ใหม่
- **ปุ่ม** ใน pane กดที่งานเพื่อสั่ง Claude ทำต่อ และมีปุ่มหยุดนับ โหมด เสียง
- **เสียง** ตอนทำเป้าหมายสำเร็จและตอนเตือนโควต้า (`/goal-meter sound off` เพื่อปิด)

## ติดตั้ง

พิมพ์ใน Claude Code แบบ terminal:

```
/plugin install goal-meter --marketplace TheerasakPing/goal-meter
```

ตอบ `y` เพื่อเพิ่ม marketplace แล้วเลือก scope (แนะนำ `user`) ใช้งานได้ทันที

**อัปเดต** เป็นเวอร์ชันล่าสุด รันใน terminal:

```
claude plugin marketplace update goal-meter
claude plugin update goal-meter@goal-meter
```

คำสั่งแรกดึงรายการเวอร์ชันใหม่ คำสั่งที่สองอัปเดตตัวที่ติดตั้งอยู่ จากนั้นเปิด session ใหม่

## ใช้ได้ที่ไหน

| ที่ใช้ | ใช้ได้ |
| --- | --- |
| Claude Code ใน terminal | ✅ ติดตั้งและใช้ได้ |
| Claude Desktop แท็บ **Code** | ✅ ติดตั้งจาก terminal แบบ scope `user` แล้วโหลดในแอปด้วย |
| Claude Code ใน VS Code, มือถือ | น่าจะได้ (ยังไม่ได้ทดสอบ) |
| claude.ai แชต, แอป Claude แชต | ❌ ไม่รองรับ mod |

โควต้าต้องใช้ subscription (Pro/Max) และขึ้นหลัง Claude ตอบครั้งแรกใน session สร้างบน API mod แบบ early access ของ Claude Code 2.1.295

## ใช้งาน

สั่งงานหลายขั้นตอนให้ Claude ได้เลย meter จะอัปเดตเองระหว่างทำงาน

| คำสั่ง | ทำอะไร |
| --- | --- |
| `/goal-meter` | แสดง meter |
| `/goal-meter <เป้าหมาย>` | ตั้งเป้าหมายเอง |
| `/goal-meter pause` · `resume` | หยุด / นับเวลาทำงานจริงต่อ |
| `/goal-meter deadline 17:00` | ตั้งกำหนดส่ง (`off` เพื่อลบ) |
| `/goal-meter report` | สรุปเป้าหมายเป็น Markdown |
| `/goal-meter history` | เป้าหมายที่เสร็จแล้ว |
| `/goal-meter mode status` · `panel` · `both` | แสดงที่ไหน (ค่าเริ่มต้น `both`) |
| `/goal-meter sound on` · `off` | เปิด / ปิดเสียง |
| `/goal-meter hide` | ซ่อนแถบเหนือช่องพิมพ์ (status line ยังอยู่) |
| `/goal-meter pane` | เปิด pane เต็ม |
| `/goal-meter clear` | ล้างเป้าหมาย |
| `/goal-meter help` | ดูคำสั่งทั้งหมด |

โหมดและการตั้งค่าเสียงถูกจำข้าม session meter แสดงได้สูงสุด 3 ที่:

- **เหนือช่องพิมพ์** แถบ 2 บรรทัด: เป้าหมาย แถบความคืบหน้า ETA งานที่กำลังทำ agent ที่กำลังทำ กำหนดส่ง และโควต้า พร้อมบรรทัดเตือนสีแดงถ้าโควต้าจะหมดก่อน
- **status line** ข้อความบรรทัดเดียว: `Goal 52% (5/11) · ◐ Build the API · ETA 14:52 | 5 ชม. 47% · สัปดาห์ 24%`
- **pane** meter แบบเต็ม: ทุกงานย่อย ค่าใช้จ่ายต่องาน คาดการณ์โควต้า agent และปุ่ม เปิดเองเมื่อเริ่มเป้าหมายในโหมด `panel` หรือ `both` หรือสั่ง `/goal-meter pane`

ใน pane: `p` หยุด/นับต่อ, `m` เปลี่ยนโหมด, `s` เปิด/ปิดเสียง, กดที่งานเพื่อสั่ง Claude ทำงานนั้นต่อ

## ทำงานอย่างไร

- **แหล่งข้อมูลงาน** tool `update` ของ mod หรือ task list ของ Claude Code (`TodoWrite`, `TaskCreate`, `TaskUpdate`) ถ้า Claude ใช้ tool `update` อยู่ รายการนั้นจะไม่ถูก task list ทับ
- **เวลา** mod จับเวลาเอง เริ่มเมื่อเห็นงานเป็น "กำลังทำ" ครั้งแรก หยุดเมื่อเห็นเป็น "เสร็จ" ครั้งแรก
- **เวลาทำงานจริง** นับจาก `turn.start` ถึง `turn.complete` ของบทสนทนาหลัก และไม่นับตอนหยุดนับ
- **ความคืบหน้า** นับงานย่อยเป็นหน่วย (งานที่ไม่มีงานย่อยนับเป็น 1) เสร็จ = 1, กำลังทำ = ½
- **ETA** = เวลาทำงานจริง × (1 − ความคืบหน้า) ÷ ความคืบหน้า × ตัวปรับ ตัวปรับคือค่ากลางของ `เวลาจริง ÷ ที่คาดไว้` จากเป้าหมายที่เสร็จ (อยู่ระหว่าง 0.5–2 และเป็น 1 จนกว่าจะมีประวัติ 2 เป้าหมาย)
- **ค่าใช้จ่ายต่องาน** = ค่าใช้จ่าย session ตอนงานเสร็จ ลบตอนงานเริ่ม
- **คาดการณ์โควต้า** ต้องมีค่าอย่างน้อย 2 ครั้งห่างกัน 2 นาทีขึ้นไปในรอบเดียวกัน

เป้าหมาย โหมด การตั้งค่าเสียง และประวัติ เก็บด้วย `$.store` จึงอยู่ข้าม session
